## What it does

W8BDCR Termux Pkg Installer installs the packages you need on Termux with a single command — no typing package names one by one.

## Quick start

```bash
git clone https://github.com/w8bdcr-official/W8BDCR-TermuxPkgInstaller
cd W8BDCR-TermuxPkgInstaller
bash install.sh
```

- Termux on Android
